# Getting help with Gooby

Trouble installing? [INSTALL.md](INSTALL.md) shows what Windows and macOS ask
the first time, and what to click.

1. **Check Settings → Help in Gooby.** It covers the common problems (empty
   recordings, a shortcut that does nothing, text that doesn't appear) and
   takes you to the setting that fixes each one.
2. **Read [TROUBLESHOOTING.md](TROUBLESHOOTING.md)** for known issues and
   fixes on each system, and the [FAQ](README.md#faq).
3. **Search the [existing issues](https://github.com/gooby-app/releases/issues?q=is%3Aissue).**
   If someone already reported it, a thumbs-up reaction and any extra detail help.
4. **[Open a bug report](https://github.com/gooby-app/releases/issues/new?template=bug_report.yml)**
   with your Gooby version (Settings → About), your system and, if you can,
   the latest log (Settings → About → Log directory). Logs leave out what
   you said; Developer mode's Logs panel shows it, so read anything you copy
   from there first.

For a question rather than a bug, ask in [Gooby's Discord](https://heygooby.com/discord).
For anything else, including privacy and legal requests, write to
[hello@heygooby.com](mailto:hello@heygooby.com).

**Security problems** go through
[private reporting](https://github.com/gooby-app/releases/security/advisories/new),
never a public issue; see [SECURITY.md](SECURITY.md).
